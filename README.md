# Void-Desktop-Installer
Este proyecto es un instalador de Entornos de Escritorio para Void, como la parte mas puñetera de Void es la instalación de Escritorios pues quise automatizarlo, y ya de paso facilitar a personas que quieran usar Void la instalación, eso si, todavía esta en Desarrollo.
